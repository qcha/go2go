# Slices Len and Cap

## Условие

Что выведен на экран следующая программа и почему? Прокомментируйте каждый шаг выполнения отдельно.

```go
package main

func main() {
    a := []int{0,1,2,3}
    b := a

    b[1] = b[len(b)-1]
    b[len(b)-1] = 0
    b = b[:len(b)-1]
    b[0] = 4

    fmt.Println(a, b)
    fmt.Println(len(a), len(b), cap(a), cap(b))
}
```

## Решение

Давайте построчно разберем то, что происходит в программе:

```go
package main

func main() {
    a := []int{0,1,2,3} // 1
    b := a // 2

    b[1] = b[len(b)-1] // 3
    b[len(b)-1] = 0 // 4
    b = b[:len(b)-1] // 5
    b[0] = 4 // 6

    fmt.Println(a, b) // 7
    fmt.Println(len(a), len(b), cap(a), cap(b)) // 8
}
```

Разберем по шагам:

1. a := []int{0,1,2,3}

    Создаёт слайс a со значениями []int{0, 1, 2, 3}

    Длина 4, вместимость 4 (len = 4, cap = 4)

2. b := a

    Создаётся слайс b, который указывает на тот же массив, что и a

    То есть a и b используют одну и ту же память

    a: []int{0, 1, 2, 3}
    b: []int{0, 1, 2, 3}

3. b[1] = b[len(b)-1]

    len(b)-1 = 3, значит берём последний элемент b[3], это число 3

    Записываем его в b[1]

    Так как a и b делят одну память, меняются оба слайса:

    a: []int{0, 3, 2, 3}
    b: []int{0, 3, 2, 3}

4. b[len(b)-1] = 0

    Последний элемент b становится 0

    То есть b[3] = 0

    Так как массив общий, a тоже видит это изменение:

    a: []int{0, 3, 2, 0}
    b: []int{0, 3, 2, 0}

5. b = b[:len(b)-1]

    Укорачиваем b на один элемент. При этом сам массив не меняется, меняется только длина слайса b!

    a: []int{0, 3, 2, 0}
    b: []int{0, 3, 2}

    У b теперь len = 3, но cap всё ещё 4

    Важно! Так как меняется только длина, то если сделать b = b[:4] (cap у нас 4 же) - то таким образом можно 'откатить' наше укорачивание.
    При этом, записать при len = 3, а cap = 4 записать в 4-ю позицию ничего нельзя - будет паника.

6. b[0] = 4

    Меняем первый элемент b на 4

    Так как b и a всё ещё используют один и тот же массив, a тоже меняется:

    a: []int{4, 3, 2, 0}
    b: []int{4, 3, 2}

7. fmt.Println(a, b)

    fmt.Println печатает только элементы в пределах длины слайса

    Поэтому a печатается полностью, а b только до длины 3:

    ```text
    [4 3 2 0] [4 3 2]
    ```

8. fmt.Println(len(a), len(b), cap(a), cap(b))

    У a длина 4 и вместимость 4. У b длина 3, но вместимость b всё ещё 4, потому что он начинается с того же места в том же массиве

    ```text
    4 3 4 4
    ```
