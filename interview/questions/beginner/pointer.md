# Pointer

## Условие

Что выведен на экран следующая программа и почему? Прокомментируйте каждый шаг выполнения отдельно.

```go
func main() {
    foo := 5 // 1
    bar := &foo // 2
    fmt.Println(*bar) // 3

    changePointer(bar) // 4
    fmt.Println(*bar) // 7
}

func changePointer(p *int) {
    newP := 3 // 5
    p = &newP // 6
}
```

## Решение

Давайте по строчно разберем то, что происходит в программе:

1. foo := 5

    Создаётся переменная foo со значением 5

2. bar := &foo

    Создаётся переменная bar, в которую записывается адрес переменной foo

    То есть bar — это указатель на foo

    foo: 5
    bar: адрес foo
    *bar: 5

3. fmt.Println(*bar)

    Разыменовываем указатель bar - это значит: "возьми значение, которое лежит по адресу bar"

    Так как bar указывает на foo, печатается значение foo:

    ```text
    5
    ```

4. changePointer(bar)

    Вызываем функцию changePointer и передаём туда bar. Аргументы передаются по значению, поэтому в функцию передаётся копия указателя bar!
    То есть внутри функции p указывает туда же, куда и bar, но p — это отдельная переменная.

    До входа в функцию:

    foo: 5
    bar: адрес foo

    Внутри функции в начале:

    p: адрес foo
    *p: 5

5. newP := 3

    Внутри функции создаётся новая локальная переменная newP со значением 3

6. p = &newP

    Теперь локальный указатель p начинает указывать на newP, но это меняет только p внутри функции! В main bar не меняется, потому что p — это копия bar.

    Было внутри функции:

    p: адрес foo
    *p: 5

    Стало внутри функции:

    p: адрес newP
    *p: 3

    В main:

    foo: 5
    bar: адрес foo
    *bar: 5

7. fmt.Println(*bar)

    После выхода из функции bar всё ещё указывает на foo, а foo всё ещё равен 5.

    Поэтому снова печатается:

    ```text
    5
    ```

    Итоговый вывод программы:

    ```text
    5
    5
    ```

При этом, если бы функция была бы такой:

```go
func changePointer(p *int) {
    *p = 3
}
```

То значение foo бы изменилось и вывод был бы:

```text
5
3
``
